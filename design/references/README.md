# Design References

Reference material for the Elite Touch Renovations design standard.

## Score baseline

[`TASTE_SCORES.md`](TASTE_SCORES.md) contains the 2026-11-25 baseline rubric scores for all page
classes. Pages scoring 47/60 (homepage, service pages, location pages, chrome) are the current
visual north star.

## Taking reference screenshots

Capture at 390×844 (mobile) and 1440×900 (desktop) using `npx playwright screenshot` or the
browser dev tools. Name files `{page-class}_{viewport}.png` — for example
`homepage_desktop.png`, `service-bathroom_mobile.png`.

Screenshots are living references. Retake them after any design change that shifts a page's
rubric score.
