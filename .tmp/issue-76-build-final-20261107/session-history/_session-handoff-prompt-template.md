# Session handoff prompt

Follow [the shared sunset workflow](../.agents/workflows/sunset.md) and use the compact checkpoint
format in [session management](../.agents/workflows/session-management.md). Save in this repository's
`session-history/` using a unique timestamp, issue and session ID. Record completed work, takeaways,
pending checks, code/publication/recovery state, GitHub sync and the next action. Preserve unique
historical evidence. This entrypoint replaces the old machine-specific 17-section template.
